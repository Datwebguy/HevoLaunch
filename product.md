# Product Requirements Document
**Product Name:** HevoLaunch  
**Hackathon:** BNB Chain – The Smart Money Era

## Vision
HevoLaunch is the premium front door for AI agents on BNB Chain.  
A clean and trustworthy marketplace where users can easily discover, evaluate, and hire agents.

## Problem
There is currently no high-quality place to find and hire agents on BNB Chain.

## Solution
HevoLaunch provides:
- Excellent category-based discovery
- Clear agent information and reputation
- Simple and smooth hiring experience
- Real on-chain data

## Mandatory Features
1. Equal depth across:
   - Rebalancing
   - Grid Trading
   - Yield Optimisation
   - Health Factor Monitoring
2. High-quality Agent Cards
3. Smooth Hire Flow
4. Real reputation data from 8004scan
5. Support for agents created with BNB Agent Studio
