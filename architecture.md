# Architecture – HevoLaunch

## Stack
- Frontend: Next.js + TypeScript + Tailwind + shadcn/ui + wagmi
- Agent Creation: BNB Agent Studio
- Identity: ERC-8004
- Discovery & Reputation: 8004scan API
- Payments & Sessions: Altana (x402 + ERC-8183)

## Core Modules
1. Discovery Engine (powered by 8004scan)
2. Agent Profile System
3. Hiring Engine (Altana)
4. Frontend Application
