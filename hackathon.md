# Hackathon Details & Agent Prompt

## What You Are Building

You are building **HevoLaunch** — a premium marketplace for AI agents on BNB Chain.

This is for the official BNB Chain hackathon **"The Smart Money Era: Build the Era"**.

### Official Goal
Build the best agent marketplace for BNB Chain.  
The winner will be officially adopted as the **BNB Agent Studio marketplace**.

### Core Problem
Finding and hiring AI agents on BNB Chain is currently difficult. There is no clean, trusted place to discover agents, evaluate them, and hire them easily.

### Mandatory Requirements
HevoLaunch **must** support these 4 categories with **equal depth**:
1. Rebalancing
2. Grid Trading
3. Yield Optimisation
4. Health Factor Monitoring

### Key Judging Criteria
- Full end-to-end journey works smoothly
- High data quality
- Equal treatment of all 4 categories

### Technical Stack
- Agents live on BNB Smart Chain
- Built with **BNB Agent Studio**
- Identity: **ERC-8004**
- Discovery & Reputation: **8004scan**
- Payments & Sessions: **Altana** (x402 + ERC-8183)

### Your Mission
Build HevoLaunch as a clean, premium, no-CLI marketplace that makes it extremely easy to discover and hire high-quality agents in the four required categories.
